# 2. convert-models.ts Implementation Analysis

## Texture Resolution Strategy

### Source: `convert-models.ts` (lines ~100-350)

**Key Functions:**
- `buildTextureIndex()` - Recursively indexes all BLP files in extraction root
- `resolveTexture()` - Multi-stage texture resolution with fallbacks
- `resolveReplaceableTexture()` - Handles TeamColor/TeamGlow replaceable textures
- `resolveFuzzyTexture()` - Last-resort fuzzy matching for legacy assets

### Texture Resolution Stages:

1. **Exact path match** - Full relative path from extraction root
2. **MDX-relative paths** - Paths relative to MDX's directory or archive top
3. **Suffix matching** - Match complete referenced suffix before basename-only
4. **Basename fallback** - Exact-basename match within same archive
5. **Fuzzy fallback** - Levenshtein distance + token matching (disabled with --strict-texture-matching)

### Replaceable Texture Handling:

```typescript
function resolveReplaceableTexture(
  replaceableId: number,
  teamColorIndex: number,
  index: TextureIndex,
  mdxRelPath: string,
  warn: (message: string) => void
): string | null {
  const kind = replaceableId === 1 ? 'TeamColor' : replaceableId === 2 ? 'TeamGlow' : null;
  const suffix = `${kind}${String(teamColorIndex).padStart(2, '0')}.blp`;
  const canonicalPath = `ReplaceableTextures/${kind}/${suffix}`;
  return resolveTexture(canonicalPath, index, mdxRelPath, warn);
}
```

- ReplaceableId 1 → TeamColor (player color indicator)
- ReplaceableId 2 → TeamGlow (player glow effect)
- Default preview uses team color index 0 (red)

## Skin Weight Handling

### Source: `convert-models.ts` (lines ~750-850)

**Classic MDX Skinning:**

```typescript
if (skin && g.VertexGroup && g.Groups && g.Groups.length > 0) {
  const joints = new Uint16Array(vertCount * 4);
  const weights = new Float32Array(vertCount * 4);
  
  // Classic MDX: average vertex's bones equally
  for (let v = 0; v < vertCount; v++) {
    const groupIdx = Number(g.VertexGroup[v]);
    const boneIds = g.Groups[groupIdx] || [];
    
    const nInf = Math.min(boneIds.length, 4);
    let wSum = 0;
    for (let k = 0; k < nInf; k++) {
      const jIdx = jointIndex.get(Number(boneIds[k]));
      if (jIdx != null) {
        joints[v * 4 + validSlot] = jIdx;
        weights[v * 4 + validSlot] = 1;
        wSum += 1;
        validSlot++;
      }
    }
    
    if (wSum > 0) {
      for (let k = 0; k < 4; k++) weights[v * 4 + k] /= wSum; // Average weights
    } else {
      // Fallback to root bone
      joints[v * 4] = rootBoneIndex;
      weights[v * 4] = 1;
    }
  }
}
```

## Coordinate System Conversion

### Source: `convert-models.ts` (lines ~350-400)

**WC3 to glTF Transformations:**

```typescript
/** WC3 Z-up → glTF Y-up: (x,y,z) → (x, z, -y) */
function wc3ToGltfVec3(src: ArrayLike<number>): Float32Array {
  const out = new Float32Array(src.length);
  for (let i = 0; i < src.length; i += 3) {
    out[i] = src[i];
    out[i + 1] = src[i + 2];
    out[i + 2] = -src[i + 1];
  }
  return out;
}

/** WC3 Rotation Quaternion conversion to glTF axis layout */
function wc3ToGltfQuat(src: ArrayLike<number>): Float32Array {
  const out = new Float32Array(src.length);
  for (let i = 0; i < src.length; i += 4) {
    const x = src[i];
    const y = src[i + 1];
    const z = src[i + 2];
    const w = src[i + 3];
    out[i] = x;
    out[i + 1] = z;
    out[i + 2] = -y;
    out[i + 3] = w;
  }
  return out;
}

/** WC3 scale → glTF scale: same axis permutation as positions, without sign change. */
function wc3ToGltfScale(src: ArrayLike<number>): Float32Array {
  return new Float32Array([src[0], src[2], src[1]]);
}
```

```typescript
function resolveTexture(
  texPath: string | undefined,
  index: TextureIndex,
  mdxRelPath?: string,
  warn?: (message: string) => void,
  allowFuzzyFallback = true
): string | null {
  // Stage 1: Exact path match
  const exact = index.fullRel.get(lower) || index.fullRel.get(lowerWithExtension);
  if (exact) return exact;

  // Stage 2: MDX-relative paths

    if (archiveHit) return archiveHit;
  }

  // Stage 3: Suffix matching
  const suffixHits = index.bySuffix.get(lower) || ...;
  if (suffixHits.length) {
    return chooseTextureCandidate(suffixHits, index, mdxRelPath, texPath, warn);
  }

  // Stage 4: Basename fallback
  const baseHits = index.byBase.get(base) || [];
  if (baseHits.length) {
    // Same-archive check before accepting basename match
    ...
  }

  // Stage 5: Fuzzy fallback (Levenshtein distance + token matching)
  if (allowFuzzyFallback) {
```

- **Stage 1**: Exact full path match (highest priority)
- **Stage 2**: MDX-relative paths (beside model or under archive top)
- **Stage 3**: Suffix matching with candidate ranking
- **Stage 4**: Basename fallback within same archive only
- **Stage 5**: Fuzzy matching with Levenshtein distance + token/context scoring

1. **Stage 2 vs Stage 4 conflict**: A texture like `Textures/orc.blp` might match both as a suffix AND as a basename, potentially causing ambiguity
2. **Fuzzy fallback warnings**: When fuzzy matching is enabled, ambiguous matches are refused with warnings - this could leave textures unresolved when they should be matched

## 4. BLP Decoding and Image Conversion

### Source: `convert-models.ts` (lines ~320-360)

```typescript
function blpToPngBuffer(blpPath: string): Buffer {
  const raw = fs.readFileSync(blpPath);
  const arrayBuffer = raw.buffer.slice(
    raw.byteOffset,
    raw.byteOffset + raw.byteLength
  );
  const blp = decodeBLP(arrayBuffer);
  const image = getBLPImageData(blp, 0);

  const width = Number(image.width);
  const height = Number(image.height);
  if (!Number.isInteger(width) || width <= 0 || !Number.isInteger(height) || height <= 0) {
    throw new Error(`BLP decoder returned invalid dimensions ${width}x${height}`);
  }

  const expectedBytes = width * height * 4;
  if (!image.data || image.data.length !== expectedBytes) {
    throw new Error(
      `BLP decoder returned ${image.data?.length ?? 0} pixel bytes; expected ${expectedBytes} RGBA bytes for ${width}x${height}`
    );
  }

  const png = new PNG({ width, height });
  for (let i = 0; i < expectedBytes; i++) {
    png.data[i] = image.data[i];
  }
  return PNG.sync.write(png);
}
```

**Findings:**
- Uses `decodeBLP` from `war3-model` package
- Decodes first mip level (index 0) only
- Validates dimensions and pixel data length
- Converts RGBA bytes directly to PNG
- Throws errors on invalid BLP data

**Potential Failure Points:**
1. **Mip level selection**: Only mip level 0 is decoded - if MDX references a different mip, it won't match
2. **Error handling**: If BLP decoding fails, texture slot remains null (no fallback to alternative textures)
3. **Image data validation**: Strict byte count check may fail on compressed/corrupted BLP files

## 7. Layer Order, Filter Modes, Alpha, and Replaceable Textures

### Source: `convert-models.ts` (lines ~480-540)

```typescript
function createLayerMaterial(
  doc: Document,
  materialIndex: number,
  layerIndex: number,
  layer: any,
  textures: any[],
  textureSlots: (ReturnType<Document['createTexture']> | null)[],
  warn: (message: string) => void
): ReturnType<Document['createMaterial']> | null {
  const textureId = Math.trunc(readStaticNumeric(layer?.TextureID, 0));
  if (!Number.isInteger(textureId) || textureId < 0 || textureId >= textureSlots.length) {
    warn(`Material ${materialIndex} layer ${layerIndex}: invalid or animated TextureID (${textureId}); layer omitted`);
    return null;
  }

  const texture = textureSlots[textureId];
  if (!texture) {
    const sourceTexture = textures[textureId];
    const replaceableId = Number(sourceTexture?.ReplaceableId ?? 0);
    if (replaceableId > 0) {
      warn(`Material ${materialIndex} layer ${layerIndex}: texture slot ${textureId} uses ReplaceableId ${replaceableId}; no team-color/replaceable texture has been substituted`);
    } else {
      warn(`Material ${materialIndex} layer ${layerIndex}: texture slot ${textureId} is unresolved; layer omitted`);
    }
    return null;
  }

  const coordId = Math.max(0, Math.trunc(readStaticNumeric(layer?.CoordId, 0)));
  const filterMode = Math.trunc(readStaticNumeric(layer?.FilterMode, 0));
  const alphaInfo = readMaterialAlpha(layer?.Alpha, warn, materialIndex, layerIndex);
  const alpha = alphaInfo.value;
  const shading = Math.trunc(readStaticNumeric(layer?.Shading, 0));

  const material = doc.createMaterial(`mat_${materialIndex}_layer_${layerIndex}`)
    .setMetallicFactor(0)
    .setRoughnessFactor(1)
    .setBaseColorFactor([1, 1, 1, alpha]);

  material.setBaseColorTexture(texture);
  const textureInfo = material.getBaseColorTextureInfo();
  if (textureInfo) {
    textureInfo.setTexCoord(coordId);
    // ... wrap settings from TextureFlags
  }

  if (filterMode === 1) {
    material.setAlphaMode('MASK').setAlphaCutoff(0.75);
  } else if (filterMode >= 2) {
    material.setAlphaMode('BLEND');
    if (filterMode >= 3) {
      warn(`Material ${materialIndex} layer ${layerIndex}: Warcraft filter mode ${filterMode} is approximated with glTF alpha BLEND`);
    }
  } else {
    material.setAlphaMode('OPAQUE');
  }

  if ((shading & 16) !== 0) material.setDoubleSided(true);
  // ... other flags reported as warnings

  material.setExtras({
    warcraft3: {
      materialIndex,
      layerIndex,
      textureId,
      coordId,
      filterMode,
      alpha,
      alphaAnimated: alphaInfo.animated,
      replaceableId: Number(textures[textureId]?.ReplaceableId ?? 0),
    },
  });
  return material;
}
```

- **Replaceable textures**: Checked after normal resolution fails
- **CoordId**: Used to select correct UV set from geoset's TVertices
- **Filter modes**: 
  - 0 = Opaque (OPAQUE)
  - 1 = Alpha masked (MASK with cutoff 0.75)

- **Alpha**: Static value or animated track (animated reported but not decoded)
- **Shading flags**: Double-sided from bit 4 (16), environment mapping from bit 1 (2) reported

**Potential Failure Points:**
1. **Invalid TextureID**: If TextureID is out of range, layer is omitted entirely - no fallback texture
2. **Replaceable texture warnings**: When ReplaceableId > 0 but no team-color texture found, warning is emitted but layer still omitted
3. **Animated alpha**: Animated tracks are reported in extras but static preview (alpha=1) is used
4. **CoordId mismatch**: If requested CoordId doesn't exist on geoset, UV set is missing - material may render with wrong texture mapping

// Proposed function to detect UV space:
function detectUVSpace(uvs: ArrayLike<number>): 'normalized' | 'non-normalized' {
  if (!uvs || uvs.length === 0) return 'unknown';
  
  const firstUv = uvs.slice(0, 2);
  const x = Number(firstUv[0]);
  const y = Number(firstUv[1]);
  
  // Check if UV is in normalized [0,1] range
  if (x >= 0 && x <= 1 && y >= 0 && y <= 1) {
    return 'normalized';
  }
  
  // Check for other common ranges
  if (x >= 0 && x <= 2 && y >= 0 && y <= 2) {
    return 'non-normalized-2';
  }
  
  return 'unknown';
}

// Apply to UV processing:
const uvSpace = detectUVSpace(uvs);
if (uvSpace === 'normalized') {
  flipped[i * 2 + 1] = 1 - Number(uvs[i * 2 + 1]); // Y-flip for WC3→glTF
} else if (uvSpace === 'non-normalized-2') {
  flipped[i * 2 + 1] = 2 - Number(uvs[i * 2 + 1]); // Different flip for [0,2] range
} else {
  warn(`UV space unknown for geoset ${gi}; using normalized assumption`);
  flipped[i * 2 + 1] = 1 - Number(uvs[i * 2 + 1]);
}

# Phase 9 — Identify lossy operations and mathematical reversibility

Create a dedicated analysis of all operations that lose information.

For each operation, classify it as one of:

- **Reversible:** The original data can be reconstructed mathematically.
- **Reversible with conditions:** The original data can be reconstructed only if additional information is retained.
- **Approximate:** The result can be approximated, but the original values cannot be recovered exactly.
- **Irreversible:** Information is permanently discarded.
- **Warcraft-specific:** The information has no direct standard GLB equivalent.
- **Exporter limitation:** The reference project does not preserve a feature even though the format may support it.

Examples to investigate include:

- Weight averaging.
- Bone influence cutoff.
- Influence count limits.
- Animation baking.
- Interpolation simplification.
- Geoset splitting.
- Vertex duplication.
- Texture conversion.

- Scale normalization.
